# Registration Form

A registration form layout with name, birth date, gender, and address fields, centered on a card. HTML and CSS forms practice.

![Registration form](docs/screenshots/desktop.png)

## What's inside

- Grouped fields for name, birth date, gender, and address
- Labels under each input, arranged in rows

## Built with

- HTML form elements
- CSS

## Run locally

No build step. Open `index.html` in a browser.
